1. ФРОНТЕНД И ИНТЕРФЕЙС (templates/index.html)
--------------------------------------------------------------------------------
- Изменения:
  1. Добавлена кастомная система Toast-уведомлений (showToast).
     * Зачем: Полностью заменены стандартные серые всплывающие окна браузера alert()
       на стильные всплывающие плашки с анимированным появлением в правом верхнем углу.
  
  2. Добавлено кастомное модальное окно подтверждения (showConfirm / confirmModal).
     * Зачем: Заменило системный confirm() браузера при удалении счетов и операций.
       Теперь выводятся сочные модальные окна с предупреждениями (⚠️).

  3. Добавлен блок "Мои счета (Wallets)" и фильтрация по картам (selectAccountFilter).
     * Зачем: Пользователь может визуально видеть все свои банковские счета/карты/наличку
       (Humo, Visa, Naqd) и кликом по любой карте фильтровать всю аналитику, графики
       и историю транзакций конкретно для этой карты.

  4. Добавлена функция удаления счетов (deleteAccount) и транзакций (deleteTransaction).
     * Зачем: Позволяет пользователю в 1 клик через иконку мусорной корзины (🗑️) удалять 
       ненужные счета или ошибочно введённые транзакции с авто-пересчетом общего баланса.

  5. Добавлено модальное окно создания счета (handleCreateAccount / createAccountModal).
     * Зачем: Дает пользователю возможность создавать неограниченное количество валютных
       счетов (UZS, USD, EUR) прямо из веб-интерфейса.

  6. Все функции JS снабжены четкими и лаконичными комментариями на русском языке.


2. БЭКЕНД И API (apps/reports/views.py)
--------------------------------------------------------------------------------
- Изменения:
  1. Исправлена ошибка типов Decimal vs float при вычислении финансовой аналитики.
     * Зачем: Ранее, когда у пользователя были только расходы, но не было доходов (или наоборот),
       Django выбрасывал исключение TypeError (500 Internal Server Error) из-за попытки
       вычесть float (0.0) из decimal.Decimal. 
       Все расчеты приведены к точному финансовому типу Decimal.

  2. Добавлена фильтрация по account_id в CategoryBreakdownReportView.
     * Зачем: Позволяет API возвращать структурированный отчет по категориям (в процентах
       и суммах) не только обще-общий, но и индивидуальный для конкретного выбранного счета.


3. АВТОРИЗАЦИЯ И ПОЛЬЗОВАТЕЛИ (apps/users/)
--------------------------------------------------------------------------------
- Изменения:
  1. Интегрирована JWT авторизация (SimpleJWT) через эндпоинты:
     - POST /api/v1/auth/login/
     - POST /api/v1/auth/register/
  2. Реализовано автоматическое сохранение JWT токена в localStorage браузера.
  3. Добавлена функция демо-входа (1-click Demo Login под логином admin / admin123).


4. МНОГОЯЗЫЧНОСТЬ И ЛОКАЛИЗАЦИЯ (apps/categories/ & templates/index.html)
--------------------------------------------------------------------------------
- Изменения:
  1. Поддержка 3 языков: узбекский (uz), русский (ru), английский (en).
  2. Переключение языка в шапке сайта мгновенно меняет заголовки интерфейса,
     названия категорий расходов/доходов и текста отчетов через HTTP-заголовок
     Accept-Language или query-параметр ?lang=.


5. АВТОМАТИЧЕСКИЕ ТЕСТЫ (python manage.py test)
--------------------------------------------------------------------------------
- Проект содержит юнит-тесты для проверки авторизации, балансов, категорий и отчетов.
- Все 4 теста успешно проходят проверку (4/4 OK).
